# AI API Monitor 文档索引

本目录按主题整理项目文档；根目录 [`README.md`](../../README.md) 是当前状态入口，历史资料不删除而移入 `Archive`。

## 目录

```text
Markdown/
├── Architecture/   架构、数据流和历史方案
├── UI/             UI 状态、Miuix/液态玻璃设计
├── API/            Provider、凭据和安全审计
├── Development/    开发指南、测试和项目索引
├── Review/         历史代码审查
├── TODO/           当前任务与优化建议
└── Archive/        历史摘要和扩展测试资料
```

## 维护规则

- 新的产品/架构说明放入 `Architecture` 或 `UI`；Provider 和安全放入 `API`。
- 可执行开发、测试和跨平台说明放入 `Development`；待办放入 `TODO`。
- 历史摘要、重复测试资料和旧版本材料放入 `Archive`，不删除重要上下文。
- 文档中的路径使用相对路径或项目根变量，不写入只适用于某台机器的绝对路径。
